# Cursor Smith is now Cursor Tweaks

This plugin has been renamed. Development continues at:

**https://github.com/akaready/thymer-cursor-tweaks**

If you already have it installed, it renames itself on next load and
re-points its own update source — no reinstall needed, and your settings
are kept. The plugin files here are left in place for that handover.

Still a port of [Cursor-Smith](https://github.com/Sadsnake1/cursor-smith) by SadSnake1 (MIT).
